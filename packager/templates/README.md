The app uses BFA3 by default when `CADILLAC_INPUT_ZIP` is not set. Every
template above has an independently verified KZB day/night record mapping;
templates without RID assets keep that factory structure and do not invent RID
files.

Keep any additional local template zips out of Git unless they are intentionally supported and redistributable.
